## 4. 問題設定の再設計(二段階アーキテクチャ、設計のみ・未実装)

診断結果を踏まえ、ユーザーから「514件の中から良さそうな部分集合を探すのは
上記§2と同じ過ちを繰り返すリスクがある」との指摘。改善案(閾値調整・
セグメント絞り込み)ではなく、問題設定そのものを見直す方向に転換。

提案した設計(実装前、特徴量・閾値の具体案は含まない):

- Stage 0: 市場の評価をベースラインとして受け入れる(71%はそのまま)
- Stage 1(新設): 「市場を上書きすべきか」を判定する独立したゲートモデル。
  selective prediction / learning-to-defer の枠組みで定式化
- ゲートモデルのターゲット候補: (a)市場失敗検知(レース単位二値分類)
  /(b)介入正否予測(候補単位二値分類)/(c)EV直接予測
- 独立性の担保、risk-coverage曲線による評価、事前登録された成功基準、
  時間分割(walk-forward)による検証、を設計要件として整理
- **最大の障壁**: 厳しいゲートほど介入件数が減り検証に必要なサンプルが
  枯渇するジレンマ。加えて今日のPhase 3で同じ514件を既に探索的に見ている
  ため、そのままゲートモデルの学習・評価に使うと二重利用(optimizer's curse)
  になる、という指摘を明記

→ `docs/gate-model-design.md`に記録(未実装、設計のみ)。
