## 2. 確定した診断結果（2026-09-02 基準点）

一次資料: [`market-disagreement-diagnosis.md`](market-disagreement-diagnosis.md)
データ: 6ヶ月バックフィル（`lib/backfill`、2026-02-05〜2026-08-05、8,683頭・1,770レース、v3=リーク除去）

| 指標 | 値 |
|---|---|
| disagreement率（モデル1位≠市場1位） | **29.0%**（514 / 1,770R） |
| disagreement時の勝率（市場1位） | 31.3%（161/514） |
| disagreement時の勝率（VH1位） | 17.1%（88/514） |
| **勝率差（VH−市場）** | **−14.2pt**　95%CI [−20.0pt, −8.2pt] |
| ROI（全レース・VH1位単勝1万円） | **−27.4%**（損益 −4,854,000円） |
| ROI（disagreementレースのみ） | **−31.0%**（損益 −1,591,000円） |
| 最大ドローダウン（全レース） | −4,854,000円（期間中一度も黒字転換せず） |
| 最大ドローダウン（disagreement限定） | −1,598,000円 |

**信頼区間が0を完全に下回っている** ＝ 「モデルが市場と違う馬を推したとき、
その判断は市場より当たらない」ことは偶然では説明できない。

### この数値は 2026-09-09 に再実行して再現を確認済み

```bash
npx tsx scripts/_diagnose-market-agreement.ts
```
上記8項目すべてが、ドキュメント記載値と**完全一致**した（誤差なし）。
診断は再現可能な状態にある。

### disagreement時にモデルが選んでいる馬の性質

極端な穴馬を推しているわけではない。**98%が「市場2〜5番人気・オッズ3〜10倍未満」**
＝ 市場の2番手評価を1番手に格上げしているだけ。
disagreement発生率はセグメント（芝ダ・距離・頭数・クラス）によらず23〜32%に収まり、
**特定の得意場面は見つかっていない。**

## 5. 方針転換：二段階アーキテクチャ（設計のみ・未実装）

一次資料: [`gate-model-design.md`](gate-model-design.md)

- **Stage 0**: 市場のオッズ順位をベースラインとして受け入れる（一致する71%はそのまま）
- **Stage 1（新設・未実装）**: 「市場を上書きすべきか」だけを判定する独立したゲートモデル
- 枠組み: selective prediction / learning-to-defer
- 評価: risk-coverage曲線、成功基準は**出力を見る前に**文書化、時間分割（walk-forward）

**最大の障壁**: 厳しいゲートほど介入件数が減り、検証に必要な標本が枯渇する。
加えて Phase 3 で既に同じ514件を探索的に見ているため、そのまま学習・評価に使うと
二重利用（optimizer's curse）になる。
→ **だから次の作業がホールドアウト凍結**（[`NEXT_SESSION.md`](NEXT_SESSION.md)）。
