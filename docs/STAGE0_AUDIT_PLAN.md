# 現行VH監査：集計前の固定条件（2026-10-09）

本監査は新モデル・条件探索ではない。development 2026-02-07〜06-21の1,338Rだけを使う。固定評価および隔離元データは開かない。

## 再現対象と限界

- 現行 engine / scorer / combination-ev / starRating の関数を変更せず利用する。
- 元のdevelopment races-cache / scores-cache v3 / horsesを照合する。新しく拡張した履歴で元スコアを置換しない。
- 最終単勝オッズ使用のため **事後市場情報を使った参考分析**。発走前の売買・当時の本番v2画面を再現したとは主張しない。
- 主集計は保存キャッシュ忠実再現（全grade=null）。本番の重賞特例を復元できないため、別集計としてrawにG1/G2/G3が明示された55Rの特例を適用する。JG1/JG2/JG3の5Rは出馬表アイコンとの対応未確認なので、この補助集計から除く。結果によって採用区画を選ばない。
- 元のキャッシュ順を維持する。同値順位の有無を記録する。欠損入力は勝手に補完せず停止する。

## 買い方・比較・集計の事前定義

- 1点1,000円固定。本番UIのEV>0.10、通常Edge>0.02かつodds<=50、重賞はEVのみをそのまま適用。
- ◎は推奨集合内のEV最大（勝率最大ではない）。全推奨単勝と市場上位N単勝を同一レース・同一頭数で比較する。◎と市場1番人気も◎が存在する同一レースで比較する。
- 別途、勝率最大馬と市場1番人気を全1,338Rで比較する。これは◎とは異なる。
- 人気は確定人気順位、同順位は馬番順。欠損を推測で埋めない。馬券内は確定複勝払戻対象、3着以内は別項目として記録する。
- 現行複合券種は現行関数の各券種上位5点を計算し、確定払戻で精算。表示オッズはHarvilleによる推定値であり実売オッズではない。UIサマリーの各券種上位3点も別名で記録する。複勝の新買い方は作らない。
- 勝率校正は全馬を10%刻みの固定区間に分ける。オッズは [1,2),[2,5),[5,10),[10,20),[20,50),[50,100),[100,∞)。星は既存0〜5の0.5刻み、実際に星を表示する補助集計の平地重賞のみ。
- ROIは純損益/投資額。円損益・最大DD・的中頻度・最長連敗・的中間隔・購入日の全敗日を併記。DDと連敗は保存発走予定時刻→raceId順で、実発走順の完全再現ではない。
- 信頼区間はレース単位bootstrap 2,000回、固定seed=20261009。同じ再標本化で比較差を算出。上位1/2件の的中払戻をゼロにしてROI符号を確認（投資額は維持する保守的感度分析）。20的中未満は候補扱いしない。本監査はそもそも改善候補の採否を決めない。
- 市場1番人気が3着外・VH推奨が3着内の事例を全件保存し、逆方向と双方不発も記録。説明例は日付/raceId順の先頭3件。利益順の抜粋はしない。
- 分解ログは強さの加算項、純モデル確率、市場logit項、最終確率、EV/Edge、条件判定、元の過去走と騎手集計を保存する。因果的寄与・アブレーション効果とは呼ばない。
- 入力/コードSHA-256と実行IDを保存。詳細ログはGit対象外のlib/simulation-runs/配下のみ。データ本体はcommitしない。

この定義は成績算出前に記録した。結果を見て閾値・区間・買い方を変更しない。
