# Stage 1 v2改善要因診断：実行前固定規約

2026-10-10。起点539f36c9120fa08a00d8615c1734248ca6e09a51。
既存[結果](STAGE1_V2_RESULTS.md)を読んだ後の監査で、未見検証ではない。
以下を詳細集計・アブレーションの出力を見る前に固定する。

- 対象は保存済み同一742R。旧平地◎/v2の予測・raw・重み・設定を変更しない。
- 入力は固定IDのv2監査summary/rowsと保存v2 A/B/C runのみ。任意パスを受け付けない。
  hash確認用に既存監査で記録された許可済みdevelopment入力と旧成果物を読む。
  fixed evaluation/封印領域は読み込み禁止。
- 推奨変更は馬IDの不一致。変更/不変を両方集計。
  変更群は勝敗2×2（v2のみ勝利/旧のみ勝利/双方勝利/双方敗戦）に分け、
  同着で異なる馬が双方勝利するケースを同一的中券と混同しない。
  各方式の勝率・複勝対象率・人気1〜18・単勝損益・DDを記録。
- 推奨差のスコアを旧5項目群、通過位置群、斤量差群に分解。
  欠損係数は対応する項目群に含む。v2の係数での説明であり因果効果ではない。
- アブレーションは保存v2スコアの加算寄与のみを除去。
  通過位置（index5/12）、斤量差（6/13）の2通りを、残り寄与・訓練平均・係数不変で実施。
  全項目保持の再計算で確率/順位を照合し、同点は既存の馬番順。
  再学習、両方除去、別の欠損処理、最適な版の採用はしない。
  これは推論時の依存性診断で、項目なしで訓練したモデルの性能や独立した因果効果ではない。
- 1R単勝1,000円、確定払戻。最終オッズ/最終人気は事後参考集計のみ。
- 上位1/2感度は必ず両方式から同じraceIdを除く。
  主方式はv2の高配当的中順、副方式は旧/v2払戻の最大値順と、
  正のレース損益差が大きい順（改善額依存性）。同額は日付/raceId順。
  払戻だけをゼロにせず、両者の当該レース投資も除く。除外後のROI/損益/DD/差を併記。
  全件・上位1/2だけを実施し、都合のよい除外数/基準を探さない。
- pairedレースbootstrap10,000回。勝率差seed20261010、ROI差は既存会計seed20261009。
  全742Rと変更群、各固定アブレーション対v2を計算。
- 広がりは変更件数、正負損益差件数/合計、既存A/B/C期間（固定境界）別で記述。
  人気/距離/馬場などから改善条件を探さない。20的中未満は参考値。
- 成功は変更群のv2勝利・旧敗戦、失敗は逆。日付/raceId順先頭3件を各方向から抽出。
  人気/配当を選択基準に使わず、抽出後の説明項目として併記する。
- 新詳細ログはGit除外の追加保存のみ。コード/文書だけcommit/push。
  既存結果は維持し、設定変更・本番反映・追加モデル実験には進まない。
