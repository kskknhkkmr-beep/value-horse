## 固定特徴量と計算

各対象レースの日前の履歴だけを使い、同日・対象raceIdも除外する。
全期間統計、オッズ・人気（過去走も含む）、旧VHスコア、馬名等の自由文は使わない。

| 特徴量 | 定義 |
|---|---|
| recentFinish | 有効過去走の直近3走までの `(頭数−着順)/(頭数−1)` の平均 |
| surfaceFinish | 今回と同じ芝/ダートの有効過去走の直近3走までの同平均 |
| distanceFinish | 同じ表面、距離差200m以内の有効過去走の直近3走までの同平均 |
| historyCount | `min(履歴件数,10)/10` |
| restDays | `min(前走からの日数,365)/365` |

有効着順はrawが整数文字列、数値列と一致、頭数2以上かつ範囲内。
中止・失格等は最下位に置換しない。条件に合う履歴の有効着順を新しい順に選ぶ。
前走日は着順の有効性に関わらず最新履歴の日付。日付同率はraceIdで決定論的に並べる。
芝/ダートの実データ表記は `芝` / `ダ`。障害は未対応。

各値は訓練区画の全出走の非欠損値の平均で中心化する。
欠損値はその訓練平均を使い、別に欠損指標を付ける（合計10項）。
履歴なし・条件に合う有効着順なしを区別し、元行・単位・平均・係数を保存する。
未観測馬は除外せず訓練内の事前値と欠損係数で扱うが、不確実性の校正は未実装。
全馬の有効過去着順がないレースは架空の等確率を作らず、予測不可と記録する。
斤量・性齢・通過順位・タイム・着差・クラス補正は初版では採用しない。

`s_i = Σ_j w_j x_ij`。同じレースの全出走馬で `p_i = softmax(s_i)`。
◎は最大スコア/確率の馬。同率は馬番順で1頭、同率フラグを残す。
相手関係は全頭のスコア比較として反映し、過去対戦相手の強さは推定しない。
全項の加算値、◎と2位の項別差・合計差を保存する。因果説明ではない。

## 固定学習規約

- 目的関数はレース平均の勝者対数損失 + `0.01/2 * Σw²`。
- 全係数0から開始。全バッチ勾配降下、学習率0.1、200ステップ。
- 乱数・早期停止・探索・ROIによる選択なし。レースを日付/raceId順に整列。
- 勝者が単独で1頭確認できる訓練レースのみ。勝者欠損/同着・未対応は理由付き除外。
- T=1固定、温度校正は延期。出力pは**未校正のモデル確率**で真の勝率と主張しない。
  校正/★VALUE・128通り・性能検証は未実装/未実行。

設計の拡大型時系列更新を1つの手順として固定する。3つの凍結重みは
同じ設定によるカレンダー更新であり、良い設定を探す3実験ではない。

| 版 | 訓練の終了日 | 訓練候補R | 予測期間 | 予測候補R |
|---|---|---:|---|---:|
| A | 2026-03-29 | 546 | 04-04〜04-26 | 264 |
| B | 2026-04-26 | 810 | 05-02〜05-31 | 336 |
| C | 2026-05-31 | 1,146 | 06-06〜06-21 | 192 |

最初の546Rは初期訓練区画で、未知データの予測を偽造しない。
予測候補は792R。障害等の未対応は残したうえで予測対象から除く。
各予測は対象日より前の結果だけで学習した重みを使う。
Aの結果が日付経過後にBの訓練に入るのは時系列更新であり、
Bの学習結果をAに遡及適用しない。同じレースの訓練内予測を評価用に保存しない。

## 実行・保存・防壁

```powershell
npx.cmd tsx scripts/test-stage1-independent.ts
npx.cmd tsx scripts/run-stage1-independent.ts
npx.cmd tsx scripts/check-stage1-capture.ts <最初のrunId>
```

入力は既存loadDevelopmentの許可済み3ファイルだけ。任意入力/設定引数は拒否。
結果・払戻はシミュレーター側の変更不可正解データで、予測後に結合するだけ。
学習境界を選んだ後、過去正解から勝者IDのみを学習関数へ渡す。
特徴量・学習・predictの中核はファイル読み取り能力を持たない。
独立入力は二段目の列限定で過去オッズ/人気も除去し、未知列を拒否する。
対象日ガード・訓練日ガード・訓練raceIdの再予測拒否を重ねる。

既存simulate/saveRunに接続し、`lib/simulation-runs/<runId>/` に
Stage 0と別版の3つのrun/manifestを上書きせず保存する。馬券は0件。
最初の版のフォルダに `stage1-capture.json` を付随保存し、全1,338Rの状態、
学習係数・補完値・訓練ID/除外理由・学習入力hash・元データhash・◎の説明を残す。
旧Runスキーマは変更しない。データ本体・学習成果物・予測はGit対象外。
runIdは正解/元ファイル全体のhashも含むので、価格変更でrunIdは変わり得るが
独立入力hashと予測は不変。これは入力への市場混入とは区別する。

## 検査・制約

合成テストで未来/同日/対象履歴の除外、市場列拒否・市場値変更不変、
未来訓練/同じレース再使用の拒否、訓練平均、再現性、説明再合計、
同着除外、全履歴不足/障害の見送り、既存シミュレーター接続を確認する。
実データでは件数・保存・日付・ID・hashだけを確認し、性能値は算出しない。
旧診断スクリプトは性能評価を行うため今回実行しない。旧基準値は変更しない。

制約：発走前の時刻付き観測ではなく結果ページから静的宣言を再構成している。
取消/除外を除いた実出走集合である。クラス・過去相手・タイム補正なし。
履歴不足の事前値は限定的。p未校正、馬券内確率・★・モデルの優位性は未検証。
fixed evaluationと `.sealed-data` は未参照。本番/取得済みデータは変更しない。
