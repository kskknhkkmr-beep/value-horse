### なぜ最初にこれをやるのか

2026-09-02 の Phase 3 で、**514件のdisagreementデータをセグメント別に
探索的に見てしまっている**（人気帯・オッズ帯・距離・クラス・頭数）。
このままゲートモデルの学習・評価に同じ514件を使うと、
「既に見た傾向を学習データに焼き込む」＝ 二重利用（optimizer's curse）になり、
**独立検証にならない。**

つまり、ホールドアウトを凍結しない限り、
**この先どんなモデルを作っても「本当に効いたのか」を証明する手段が無い。**
だから他のすべてに優先する。
