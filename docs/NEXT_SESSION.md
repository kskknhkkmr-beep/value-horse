> ## 今後のdevelopmentから分離した固定評価区画として凍結する

- fixed evaluation: 2026-06-27〜2026-08-02（432R）

詳細と解禁条件は [`FIXED_EVALUATION.md`](FIXED_EVALUATION.md) を参照。

### 経緯

[`gate-model-design.md`](gate-model-design.md) §5 で、進め方の選択肢が3つ提示された。

1. データ蓄積を継続し、設計だけ先に固める
2. **過去データを時間分割し、直近の一部を凍結してホールドアウトにする** ← オーナーが選択
3. 紙上運用（paper trading）で判定だけ記録し続ける

**オーナー（一星）は 2 を選択した。** この判断は確定しており、覆さないこと。

### なぜ最初にこれをやるのか

2026-09-02 の Phase 3 で、**514件のdisagreementデータをセグメント別に
探索的に見てしまっている**（人気帯・オッズ帯・距離・クラス・頭数）。
このままゲートモデルの学習・評価に同じ514件を使うと、
「既に見た傾向を学習データに焼き込む」＝ 二重利用（optimizer's curse）になり、
**独立検証にならない。**

つまり、ホールドアウトを凍結しない限り、
**この先どんなモデルを作っても「本当に効いたのか」を証明する手段が無い。**
だから他のすべてに優先する。

### 完了の定義（これが揃うまで次に進まない）

- [x] 時間分割の分割点（日付）を決め、**根拠とともに文書化**する
- [x] 固定評価区画を物理的に分離し、通常の分析パイプラインから
      読めない状態にする
- [x] 「凍結した」ことと「解禁条件」（何を検証するときに一度だけ開けるか）を
      文書に残す
- [x] 凍結後、**fixed evaluationの成績を見ない**（件数・日付・ID整合性のみ検証）
