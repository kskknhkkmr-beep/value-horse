## 分母と再現方法

1,338R（2026-02-07〜06-21）、18,870出走、7,851ユニーク馬、保存履歴85,395行。
各出走をhorseIdで結び、`history.date < targetRace.date` かつ対象raceIdでない行だけを抽出。
履歴を使うたび数えると180,131行、horseId＋元配列位置で重複を除くと75,733行。
以下の履歴表は**この75,733行**が分母。全保存行の取得率と混同しない。
使用可能行の日付範囲は2018-07-01〜2026-06-14。

対象日以後・同日の除外は延べ40,536行、そのうち対象自身の行は18,870行（重複する分類）。
履歴なしは1,126/18,870出走=5.97%。前走ありは17,744出走。
3走以上14,520出走、5走以上11,300出走。馬単位ではなく出走単位の件数。

確認はPowerShell内の読み取り専用NodeコードでJSONをメモリ上に読み、上記日付フィルター、
ID結合、null/空文字検査と下記の形式検査のみ実施。結果ラベルを予測や性能計算へ結合していない。
品質数値の全履歴分母は[raw基盤の旧調査](STAGE1_RAW_DATA.md)とは異なる。

## 現在レースの項目

実出走18,870頭に限る性・齢・斤量・騎手/ID・調教師/ID・枠番・馬番は全て空欄0。
馬体重rawも空欄0だがresult側に保存され、発走前観測を証明できない。
レースの馬場・天候・発走予定時刻・クラスraw/structuredは1,338件全て存在。
gradeのnullは1,278件（非重賞の正常値）。残り60件にはJG5件を含む。

- 性齢・斤量・枠・騎手等は「事前に通常公表される静的情報の結果ページからの再構成」。
  取得時刻は事後であり、当時の発表・変更時刻まで証明したデータではない。
- 馬場・天候・現在馬体重は**事前時刻の証拠が全件不足**。初版の入力から除外する。
  preRaceという保存キー名だけで事前利用可と判断しない。
- 出走馬集合は確定実出走馬。取消等71頭の発表時刻の証拠はない。
- 歴史のクラスは専用フィールドなし。現在developmentのレース辞書へ結べる使用可能履歴は
  11,060/75,733=14.60%。raceNameだけから全ての特別戦のクラスを推測しない。
- 馬戦績を同一raceIdで寄せて、記録されたユニーク馬数と頭数が一致する履歴行は
  12,621/75,733=16.67%。不一致62,961行、判定不能151行。
  **頭数一致だけの候補数**であり、全馬・日付・馬番・数値項目の完全性を保証しない。
  development辞書への結合14.60%と同じ条件／分母の意味ではない。
- 7,851頭はこの期間の出走馬から選ばれた集合。他時点の対戦相手が全頭入るとは限らず、
  対戦レースの欠けた一部を「全相手」と見なした能力・騎手成績は偏る。
