# Top3 v2 相手候補診断

2026-11-11。保存済みdevelopment 742Rのみ。モデル実行・再学習・新特徴量・本番変更なし。

## 集計前に固定した定義

Top3 v2の◎と全馬順位を固定。人気は保存された最終人気順位（同人気は馬番順）の事後参考値。
相手は軸をhorse IDで除いてから選ぶ。A=VH上位4頭、B=市場上位4頭、
C=市場上位3頭の後に未選定VH上位1頭、D=市場上位2頭の後に未選定VH上位2頭。
市場候補を先に並べ、残りをVH順に補充する。人気薄を強制しない。
ワイドは相手先頭3頭・3点各1,000円。三連複は4頭から2頭・6点各1,000円。
このためCのワイドはBと完全同一、DのワイドにはVH枠が1頭だけ入る。結果後に順序を変えない。
E=市場1番人気軸＋市場相手を基準として残す。Eのみ軸が異なるため因果的な相手効果とはしない。

市場1〜5順位のVH上位5包含率は軸も含む。軸一致は相手の取りこぼしと呼ばない。
軸Top3条件付き除外率は全軸Top3レースと、当該市場馬が軸でないレースの両分母を示す。
責任分離は数値着順Top3外、Top3内だが公式組合せに不在、公式組合せ参加可能だが相手失敗、的中を別計数する。
Top3と公式券的中は同じではない。同着を含め、全券は既存settleTicketで確定払戻と照合する。
相手捕捉率の主定義は軸Top3条件付きの公式券的中率。補足に公式的中相手/組合せの捕捉率も残す。

対応付きレースbootstrap10,000回、seed20261111。全5方式に共通の再標本列で的中率・ROI差を計算。
条件付き率差は同じ軸のA〜Dでのみ計算する。多重比較未補正。20的中未満は参考値。
高配当は券種別・全5方式の単券払戻最大値順、同点は日付/ID順で上位1/2Rを共通除外。
事例は軸Top3かつA外れ/B的中（公式的中相手に市場上位5が含まれる）、逆A的中/B外れを
日付→race ID順で各最大10R。配当や人気薄度で例を選ばない。全買い目と馬ID対応を保存する。
最終人気・確定払戻・事後実出走集合を使う既知742Rの記述診断。最良ROI方式を採用せず停止する。
固定評価・隔離領域は存在確認も行わない。

## 結果

対象は2026-04-04〜06-21の同一742R・10,583出走。development1,338R内の平地1,292Rから、初期平地527R・後続材料不足23Rを除いた既存集合。
保存Top3 v2の◎387/742Rが3着以内。市場基準軸は487R。軸選定の再実行や入力への市場混入はない。
既存summary・plansと元developmentの結果/公式払戻を馬ID・馬番で照合。A/B/Eは保存済み精算を再利用し、既存の全会計項目が一致。
新しいC/D買い目は結果を精算へ渡す前に別保存・読み戻し照合。固定742ID hashを照合し、除外追加0。
