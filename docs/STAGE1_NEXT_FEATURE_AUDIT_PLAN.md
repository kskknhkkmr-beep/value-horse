# 次期特徴量・失敗構造監査の固定規約

2026-10-10、結果集計前に固定。対象は保存A〜Dの共通742Rのみ。
既存アブレーションの42ファイルhashと保存予測の選択馬を照合し、元データ/モデルを保持する。
学習・推論の再実行、新特徴量の生成、ROI条件探索を行わない。

## 構造上の問い

- 着順/頭数の平均は過去クラスや相手強度を区別しない。不足の範囲を調べるが敗因と断定しない。
- 同表面・距離±200mの直近有効3走平均は根拠件数や距離変更を独立入力にしていない。
- 馬場履歴があっても今回馬場の事前時刻がなければ今回適性を再現できない。
- 相手集合が揃っても、その過去日以前の相手履歴が必要。後の出世は使わない。

## 固定する集計

Dと最終市場1番人気の一致/不一致。双方の勝率・確定複勝対象率・人気分布。
不一致の条件は既存カテゴリの芝ダ、実距離m、場、保存クラス/格、保存馬場の件数のみ。
条件別ROI/勝率による選別、条件境界の変更はしない。
差CIは対応付きレースbootstrap10,000回、seed20261010。
複勝対象は確定払戻の定義を維持し、3着内と区別する。

品質分母は共通742Rの全出走延べ、厳密に対象日より前の平地履歴の
horseId＋元行番号による和集合、D/市場の選択馬。それぞれ分母を明記する。
同日・未来・対象自身・障害/不明を除く。外部/地方/海外はJRA確認と分ける。
クラスは既存developmentのraceId＋日付結合と、名前に明示されたカテゴリのみの
監査用識別に区別し、特別戦名から補完しない。識別をモデルへ実装しない。
相手はdevelopment過去レースの全実出走・馬番・頭数一致を確認する。
7,851馬から寄せた部分集合を全相手とみなさない。

事例は日付/raceId順で最初3件ずつ：
(1)市場勝利かつD複勝対象外、(2)D勝利かつ市場複勝対象外、
(3)双方複勝対象外。不一致内に限り、価格・人気・条件で選別しない。
同じ品質要約を全3集合の双方に提示し、支持・反証を両方残す。

候補は最大3つ、データ品質・競走の構造・実装可能性からのみ提案する。
有効性が確認された統計的/EV候補ではない。モデルの正式採用や改良へ進まない。
封印領域・固定評価432R・本番にはアクセスしない。
