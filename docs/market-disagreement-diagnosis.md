# VALUE HORSE 市場乖離診断 — 2026-09-02 基準点

**目的は診断のみ。改善提案は含まない。** 「VALUE HORSE（VH）は市場に対して、
どの場面で、どの程度、どの方向へ誤差を出しているか」を定量化した記録。
今後モデル・特徴量・閾値を作り直した際に、**同じスクリプトを同じデータに対して
再実行し、下記の基準点と数値を比較する**ために残す。

- データ: 6ヶ月バックフィル（`lib/backfill`、2026-02-05〜2026-08-05、v3=リーク除去、
  8,683頭・1,770レース）
- スクリプト: `scripts/_diagnose-market-agreement.ts`
- 再実行: `npx tsx scripts/_diagnose-market-agreement.ts`
- 定義:
  - **VH1位** = 最終ブレンド確率（純モデル65%＋市場35%、`lib/engine.ts`の`probability`）が
    最大の馬
  - **市場1位** = 最終オッズが最小の馬（公正市場確率が最大の馬と同義）
  - disagreement = 1レースにつきVH1位と市場1位が別の馬であること

| | 勝率 | 95%CI |
|---|---|---|
| 市場1位の勝率 | 161/514 = 31.3% | [27.0%, 35.2%] |
| VH1位の勝率 | 88/514 = 17.1% | [13.8%, 20.6%] |

**CIが0を完全に下回っており、disagreement時は市場1位のほうがVH1位より
明確に勝率が高い。** VALUE HORSEが市場の一番人気と異なる馬を1位評価したとき、
その判断はおおむね市場より当たっていない。

## 今後の再診断について

このレポートは**2026-09-02時点のVALUE HORSEの挙動を写した基準点**であり、
改善提案は一切含まない。モデル・特徴量・閾値・スコア算出ロジックを変更した際は、
`scripts/_diagnose-market-agreement.ts`を（対象データセットを差し替えて）
再実行し、上記6項目（disagreement率／勝率差とCI／ROI2系統／最大DD2系統）を
この基準点と並べて比較する。

- スクリプトは`CACHE_DIR`/`SCORES_FILE`/`TARGET_VERSION`をトップの定数で
  直接書き換える形（他の分析スクリプトのようなenv変数化はまだしていない）。
  データセットを差し替えて再実行する場合はその3定数を書き換える。
- 本診断はv3（リーク除去）のみで実施。v2との比較は行っていない
  （必要なら同じ書き換えで再実行可能）。
- 何をもって「改善」と呼べるかの判断基準（disagreement率が下がるべきか、
  勝率差のCIが0を跨ぐようになるべきか等）は、本レポートでは定めない。
