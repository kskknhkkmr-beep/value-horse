# Stage 1 v2：通過位置・前走斤量差の固定規約

2026-10-10。起点abae25727c2e82da6f439229690cb676276ae00d。新版本番反映なし。
[弱点調査](STAGE1_WEAKNESS_RESEARCH.md)、[平地基準点](STAGE1_FLAT_BASELINE.md)、
[独立設計](STAGE1_INDEPENDENT_DESIGN.md)に従い、性能を見る前に定義を固定する。

- 旧5特徴量・旧コード・旧予測・監査は不変。v2は2数値と各欠損指標だけ追加（計7数値＋7欠損）。
- 現在/過去のオッズ・人気、対象結果・払戻は入力禁止。性齢/クラス等の追加はしない。
- 通過位置：対象日前・対象raceId以外、確認済みJRA平地・今回と同表面の新しい3走を先に選ぶ。
  各走は完走の整数着順と頭数>=2、通過列は1〜4区間の整数ハイフン列、
  全順位が1〜頭数。最後の順位kで(fieldSize-k)/(fieldSize-1)、有効値だけの平均。
  4走目に遡って欠損を埋めない。全欠損はnull。raw・区間数・使用件数・不採用理由を保存。
  現在の区間タイム/通過は使わず、最後の通過は同一コーナー/直線の保証ではない。
- JRA確認は12桁raceIdの場コード01〜10と、保存venue（札幌/函館/福島/新潟/東京/中山/中京/京都/阪神/小倉）の一致。
  地方/海外/ID欠損・不整合は追加2項目では不適格。既存5項目の母集団は変更しない。
- 斤量差：同日/未来を除いた直前走をまず特定。直前が非JRA/障害/不明ならnull、古い走へ代替しない。
  直前日が複数履歴で曖昧、または取消/除外の行ならnullとして理由を記録する。
  rawは単純な数値kgだけ（**等は欠損）。今回rawと数値列が両方あれば一致を要求。
  対象斤量も結果ページの静的宣言再構成で、発走前の観測時刻の証拠はない。
  学習値は(今回kg−前走kg)/10。因果的な軽量効果とは呼ばない。
- 通過/斤量差は欠損でも訓練内平均補完＋欠損係数を使う。新項目だけでレースを除外しない。
  非平地の過去走は前走の欠損判定用の日付/種別マーカーのみ残し、数値は入力へ渡さない。
- 訓練は旧A/B/C窓、200ステップ・学習率0.1・L2=.01・T=1・全係数0から開始、探索なし。
  係数は7項目＋欠損の14個。追加以外の学習方式を変えない。
- 平地development1,292R、初期平地527Rは評価せず、後続平地765Rで予測。
  旧平地◎の保存742Rを対照に、同じraceId・実出走集合・見送り規約で比較する。
  見送りが変われば全件の理由と共通集合を報告し、黙って比較集合を選び直さない。
- 1R単勝1,000円、確定払戻、最終市場対照は事後参考。勝率・複勝対象率・ROI・損益・DD・連敗。
  市場一致/不一致は両群とも表示し、購入条件にしない。
- 主指標はv2−旧平地◎の勝率差。対応付きレースbootstrap10,000回、seed20261010、95%CI。
  下限>0ならdevelopment内の順位改善を示唆、0を含めば不明、上限<0なら悪化。
  複勝率差CI・対数損失/Brierも退行確認用の固定副指標。副指標で主指標を合格に変えない。
  同着勝者の確率評価は未定義なので対数損失/Brierだけから除外し、件数/IDを記録する。
  同着レースの勝率・払戻評価は既存どおり残す。
  ROIの既存会計bootstrapはseed20261009を維持して再利用し、種別を明記する。
- 高配当上位1/2件の損益/ROI感度、的中Jaccard、的中20件未満は参考の規約を維持する。
  欠損/使用率と全馬・◎の寄与を記録。各方向の例は日付/raceId順先頭3件、成功だけ選ばない。
- raw不変、旧成果物不変、新capture/run/監査は追加保存してGit管理外。
  予測を保存・構造確認してから性能を一度確認し、設定を再調整しない。
- 128通り・★・本番・固定評価/封印領域は対象外。
  全1,770R基準スクリプトは固定評価を含むので実行せず、既存基準値は保持する。
